01 模板鼠构成 · CONSTRUCTION

几何 · 7 组剪影碎片（身体 / 头 / 耳 / 手臂 / 后脚 / 前腿 / 前脚）+ 安全帽 + 电钻 + 红色闪电 / 眼睛 + 尾巴 + 胡须。

视口 · 270 × 240，单色 currentColor 剪影；瞳孔 / 闪电固定信号朱红 #FF3B1D。

动效 · 瞳孔随光标移动；耳朵随机抽动；尾尖随滚动速度摆动（Lenis/scroll velocity）；悬停碎片错位抖动；VI 页演示尾巴 4–9s 轻甩、电钻 6–12s 间歇工作（rat-motion.js，可暂停）。

字体选型 / TYPEFACE

    
从三款免费可商用的等宽粗体中选定 Chivo Mono 700：字宽、字重与灰度最接近上一版字体，grotesque 骨架 + 方切终端，工业感够用又不抢图形。字体以 woff2 子集交付：10,756 bytes，覆盖 Basic Latin、Latin-1、常用标点与 ≤ ≥ × —；箭头 ← → ↑ ↓ 不在字体字符集内，按系统等宽回退。所有文字仍只用这一字体族，不引入第二款字体。

    

      
候选风格判断授权 / 官方来源结论

      
        
Chivo Mono 700最接近原字宽度与灰度；grotesque 骨架、方切终端，工业但不花。SIL OFL 1.1 · Omnibus-Type/Chivo · Google Fonts采用

        
Martian Mono 700工业信号最强，但字面更宽、更圆，密集表格里占位明显。SIL OFL 1.1 · evilmartians/mono备选

        
Azeret Mono 700窄、干净、技术感；性格最弱，更像通用 coding mono。SIL OFL 1.1 · displaay/azeret备选

      
    

    
字体重命名与再分发遵循 OFL：保留版权与许可文本；不单独售卖字体；修改版不占用原作者名义。许可全文：OFL-ChivoMono.txt。字体文件：ChivoMono_Bold.woff2。
站点接入：目标路径 /fonts/ChivoMono_Bold.woff2；由网站会话替换 site.css 与 dataviz.js 的旧字体引用。本页已使用新字体。

07 动效 / MOTION

    
07.1 Logo 动效 / LOGO MOTION

    
工程鼠的两组微动效：尾巴每 4–9s 轻甩一次（480ms）；电钻每 6–12s 间歇工作一次（520ms，短促高频抖动 + 钻头火花）。动作只作用于页面实时渲染，不改 rat.js，也不影响静态 SVG 下载。

    

      

        LIVE / 实时渲染
        
      

      

        
演示 / DEMO

        
开关只影响本页演示。系统开启“减少动态”时默认关闭；页面不可见时自动停表。

        

          
          
          
          
        

        
运行中 · 尾巴 4–9s / 电钻 6–12s

        
频率为随机区间，不是固定节拍；每次动作短促、结束即停，不做循环旋转或持续呼吸。

      

    

    

      
项目规范

      
        
何时用VI / 品牌演示页、官网导航或页脚的动态 Logo、社交头像动图（可选）。只在品牌自有触点使用。

        
尾巴间隔 4–9s 随机；单次 480ms；0° → +9° → -3.5° → +1.2° → 0°；绕尾根旋转。

        
电钻间隔 6–12s 随机；单次 520ms；9 段 52ms 高频位移 / 旋转抖动，钻头火花闪 2 次。

        
缓动尾巴 cubic-bezier(.22,1,.36,1) 起手、cubic-bezier(.37,0,.63,1) 回位；电钻 steps(1,end)，要“顿”不要“滑”。

        
自动停止prefers-reduced-motion: reduce 默认关闭；页面不可见、用户暂停、打印时停止。

      
    

    
禁用 / DON'T

    
    
      
  • 不做持续循环、呼吸、漂浮或无限旋转；动效必须短促、有间歇。
    • 
      
  • 不改瞳孔 / 闪电红色，不给电钻加渐变、发光或大面积光效。
    • 
      
  • 不在 22px 顶栏、favicon、印刷稿、静态 SVG 下载里加动画。
    • 
      
  • 不忽略用户的“减少动态”设置：默认关闭，只有用户手动开启才运行。
    • 
      
  • 不让尾巴和电钻同时触发；同一时刻只做一组动作。
    • 
      
  • 不把动效当加载动画、警示或交互反馈使用；它只是品牌性格。
    •

缓动 token / EASING

    

      
Token值用途来源

      
        
--ease-outpower2通用出场全站最常见（18 处）

        
--ease-in-outpower1.inOut对称过渡多处

        
--ease-strongpower4.inOut强对比转场多处（17 处）

        
--ease-enterpower4入场多处

        
--ease-exitpower4.in退场多处

        
--ease-uipower3.outUI 反馈菜单 / 导航
